# terraform-aws-eks-cluster

Opinionated EKS cluster module for the `jose-merchan` HCP Terraform Private Module Registry.

Wraps the [`eks`](https://app.terraform.io/app/jose-merchan/registry/modules/private/jose-merchan/eks/aws) and [`vpc`](https://app.terraform.io/app/jose-merchan/registry/modules/private/jose-merchan/vpc/aws) private modules to provide a production-ready EKS cluster with sensible security defaults.

---

## Features

| Feature | Default | Configurable |
|---|---|---|
| KMS encryption for Kubernetes secrets | ✅ Always on | Key rotation period |
| IRSA (IAM Roles for Service Accounts) | ✅ Enabled | `enable_irsa = false` to disable |
| Private API server endpoint | ✅ Always on | — |
| Optional public API server endpoint | ❌ Off | `endpoint_public_access = true` |
| Control-plane audit logging | ✅ All types | Log retention days |
| VPC Flow Logs | ✅ Always on | — |
| EBS encryption on worker nodes | ✅ Always on | — |
| Create a new VPC | ✅ Default | Pass `vpc_id` to use existing |
| Internet access from private subnets | ✅ Enabled | `enable_internet_access = false` |
| Single vs. per-AZ NAT Gateway | ❌ Per-AZ | `single_nat_gateway = true` |
| Multiple node groups / node pools | ✅ Supported | `var.node_groups` map |
| Configurable instance type per group | ✅ Supported | `instance_types` list per group |
| Mandatory tags | ✅ Enforced | `additional_tags` to extend |

---

## Security defaults (non-overridable)

- `endpoint_private_access = true` — the private endpoint is always enabled.
- `create_kms_key = true` with `enable_kms_key_rotation = true`.
- All five control-plane log types forwarded to CloudWatch.
- EBS volumes on every node group are encrypted.
- Public endpoint CIDRs are validated to reject `0.0.0.0/0`.
- Log retention enforced to ≥ 90 days.

## Usage

### New VPC (default)

```hcl
module "eks_cluster" {
  source  = "app.terraform.io/jose-merchan/eks-cluster/aws"
  version = "~> 1.0"

  # Mandatory tags
  environment = "prod"
  owner       = "platform-team"
  cost_center = "CC-1234"
  project     = "payments"

  # Cluster
  cluster_name       = "payments-prod"
  kubernetes_version = "1.33"

  # Node groups
  node_groups = {
    system = {
      instance_types = ["m6i.large"]
      min_size       = 2
      max_size       = 4
      desired_size   = 2
      disk_size_gb   = 50
    }
    workers = {
      instance_types = ["m6i.xlarge", "m6a.xlarge"]
      min_size       = 1
      max_size       = 10
      desired_size   = 3
      disk_size_gb   = 100
      capacity_type  = "SPOT"
    }
  }

  # Network — a VPC is created automatically
  availability_zones  = ["us-east-1a", "us-east-1b", "us-east-1c"]
  vpc_cidr            = "10.10.0.0/16"
  private_subnet_cidrs = ["10.10.0.0/19", "10.10.32.0/19", "10.10.64.0/19"]
  public_subnet_cidrs  = ["10.10.128.0/20", "10.10.144.0/20", "10.10.160.0/20"]
  enable_internet_access = true
}
```

### Bring-your-own VPC

```hcl
module "eks_cluster" {
  source  = "app.terraform.io/jose-merchan/eks-cluster/aws"
  version = "~> 1.0"

  # Mandatory tags
  environment = "staging"
  owner       = "platform-team"
  cost_center = "CC-5678"
  project     = "api-gateway"

  # Cluster
  cluster_name = "api-gateway-staging"

  # Provide existing VPC and subnets — no VPC is created
  vpc_id     = "vpc-0abc123def456789"
  subnet_ids = ["subnet-aaa", "subnet-bbb", "subnet-ccc"]

  # Node group
  node_groups = {
    default = {
      instance_types = ["t3.xlarge"]
      min_size       = 1
      max_size       = 5
      desired_size   = 2
    }
  }
}
```

### Private cluster (no public endpoint)

```hcl
module "eks_cluster" {
  source  = "app.terraform.io/jose-merchan/eks-cluster/aws"
  version = "~> 1.0"

  environment = "prod"
  owner       = "infra"
  cost_center = "CC-9999"
  project     = "internal-platform"

  cluster_name           = "internal-prod"
  endpoint_public_access = false  # fully private cluster

  node_groups = {
    default = {}
  }
}
```
