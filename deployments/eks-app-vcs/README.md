# eks-app-vcs

VCS-driven HCP Terraform workspace that deploys an NGINX application onto the
EKS cluster created by `eks-infra-vcs`.

## How it works

- **Run trigger**: this workspace is automatically queued whenever `eks-infra-vcs`
  completes a successful apply (configured in HCP Terraform).
- **Remote outputs**: cluster connection details are read at runtime via
  `data "tfe_outputs" "infra"` — no hardcoded values.
- **No AWS credentials needed in this repo**: dynamic credentials come from the
  global variable set `aws-dynamic-provider-credentials`.
